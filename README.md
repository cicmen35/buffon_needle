### Installation
- Python 3.9+

- **macOS / Linux**:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
- **Windows**:
     ```cmd
     python -m venv venv
     venv\Scripts\activate
     ```
- **requirements**
    ```bash
    pip install -r requirements.txt
    ```

### Run project
```
streamlit run app.py
```
